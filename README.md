🚀 A modern educational and software services platform developed for **Fanavaran Farda Sirjan**.

Fanavaran Farda Sirjan is a programming academy and software development company focused on empowering students, professionals, and businesses through technology, education, and innovation.

## 🌟 About

This project is designed to provide a complete digital ecosystem for managing educational programs, students, instructors, courses, classrooms, attendance, finance, and administrative operations.

The platform aims to streamline learning management while delivering a professional experience for students, instructors, and administrators.

## ✨ Features

- User Authentication & Authorization
- Role-Based Access Control (Admin, Teacher, Student)
- Student Management
- Staff & Instructor Management
- Course Management
- Classroom Management
- Attendance Tracking
- Financial Management
- Course Content Management
- FAQ & Support System
- Dashboard & Reporting
- Secure API Architecture
- Responsive User Interface

## 🛠️ Technologies

### Backend

- FastAPI
- SQLAlchemy
- SQLite / PostgreSQL
- JWT Authentication
- Pydantic

### Frontend

- React
- React Router
- Bootstrap
- Vite

## 🎯 Project Goals

- Simplify educational center management
- Improve student experience
- Automate administrative processes
- Provide scalable software architecture
- Support future growth and new features
